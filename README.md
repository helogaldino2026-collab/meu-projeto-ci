# Calculadora Espacial - Projeto CI/CD

Projeto web simples com Backend (Node.js + Express) e Frontend (HTML/JS) desenvolvido para aplicar testes automatizados, Integração Contínua (CI) e Deploy Contínuo (CD).

## Como rodar o projeto localmente
1. Instale as dependências:
   `npm install`
2. Inicie o servidor:
   `npm start` ou `node server.js`
3. Acesse no navegador: `http://localhost:3000`

## Como rodar os testes automatizados
Execute o comando:
`npm test`
## Aplicação Online (Deploy)
Acesse o projeto funcionando em: https://meu-projeto-ci.onrender.com
